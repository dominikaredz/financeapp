# 💰 Personal Finance Manager

A web application designed for personal budget tracking and expense analysis, integrated with automated transaction notification processing.

🌐 **Live Demo:** [https://domiredz00.pythonanywhere.com/](https://domiredz00.pythonanywhere.com/)

---

## 🚀 Features

* **Transaction Tracking:** Log, categorize, and analyze income and daily expenses.
* **Automated Notifications:** Integration with **MacroDroid** to capture and process incoming device notifications (e.g., bank push notifications).
* **SQL Database:** Relational data storage for user accounts, categories, and financial logs.
* **Dashboard Overview:** Clear summary of current financial status and history.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Database:** SQL / SQLite (Django ORM)
* **Automation:** MacroDroid
* **Frontend:** HTML5, CSS3, JavaScript
